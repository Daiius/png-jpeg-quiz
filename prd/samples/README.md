# prd/samples

仕様策定中の**議論用サンプル**を置く場所（実際の問題素材ではない）。

- 「この画像は良問か」「意地悪問題としてどこまで許容するか」を判断するための現物。
- 置くときは**出典・作者・ライセンス**を併記する（[../05-content-pipeline.md](../05-content-pipeline.md) §1）。
- 実測値（PNG / JPEG のバイト数と条件）が取れていれば一緒に書く。

> 本番の素材置き場は `assets/source/`（→ [../05-content-pipeline.md](../05-content-pipeline.md) §2）。
